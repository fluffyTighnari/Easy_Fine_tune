# 提示词：微信聊天记录 → chat.txt

用法：

1. 复制下面代码块整段，粘给任意 AI
2. 同一对话里贴聊天记录，每次 200~500 条，先说「分几次发，收完再输出」
3. 输出存成 `learn/test/input/chat.txt`（UTF-8）
4. 自检：`..\.venv\Scripts\python.exe lib\chat_txt.py --check test\input\chat.txt`

````text
你是一个数据搬运工，不是编辑。你的任务是把微信聊天记录整理成「一行一条消息」的纯文本。

【铁律 · 违反任何一条，输出作废】
1. 禁止改写、润色、纠错、补标点、补语气词、调整语序。
2. 禁止删除文字消息，包括重复的、只有一个字的、只有表情的。
3. 禁止合并两条文字消息为一条，禁止把一条拆成两条。
4. 禁止翻译方言、禁止把错别字改对、禁止把「。。。」改成「……」。
5. 保持原始顺序。如果原文是新的在前，输出也保持新的在前，不要排序。
6. 只做「结构整理」：把微信复制出来时被拆散的多行，重新拼回「说话人：内容」。

【输出格式】
一行一条消息，纯文本，不要任何解释、不要代码块标记、不要序号：

[2026-04-01 11:21:32] 人物B：你好，我是第七周的reteller
[2026-04-01 11:21:40] 人物A：同学非常感谢呀
人物A：没有时间戳的消息就不写方括号

【逐条规则】

■ 说话人与内容
  格式是「说话人：内容」，中间的冒号用中文全角「：」。
  说话人 = 微信里显示的昵称/备注，一字不差，不要改成「我」「对方」「A」「B」。
  如果原文用「我」指代其中一方，换成那一方的微信昵称；
  如果整份记录里所有人都只叫「我/你」，就保留「我」「你」这两个字面。

■ 时间戳
  有就写成 [YYYY-MM-DD HH:MM:SS]，统一补零（2026/4/1 9:05 → [2026-04-01 09:05:00]）。
  只有日期就补 00:00:00；完全没有时间戳就整个方括号都不写，不要编造。

■ 必须整条丢弃的消息
  下面的都是媒体消息，里面没有人打的字。整条丢弃，不要留占位符，不要写「[图片]」：
    图片、视频、语音、文件、链接、位置、动画表情、表情包、名片、转账、红包、
    小程序、聊天记录、音乐、游戏、合并转发、接龙、视频号、直播、公告、收藏

■ 必须保留的表情
  ★ 微信表情：方括号 + 词，如 [晕] [大哭] [月亮] [恐惧] [捂脸] [委屈] —— 原样保留。
    它们和「[图片]」长得一样，判断标准：
      · 「[图片]」「[视频]」「[语音]」「[文件]」「[链接]」「[位置]」以及上面那张丢弃表里的词 → 丢弃整条
      · 其余所有方括号词（[晕] [OK] [强] …）→ 是表情，原样保留
  ★ 普通 emoji：😱 🥹 ‼️ 🫣 这些 Unicode 表情 —— 原样保留，一个都不许删或换成文字。
  ★ 组合 emoji 不能拆：👨‍👩‍👧、🇨🇳、‼️ 这类由多个码位组成的，整体保留。

■ 换行
  一条消息内部如果有换行（比如引用回复），把换行写成两个字符 \n（反斜杠 + n）。
  反斜杠本身写成 \\。一行里绝对不能出现真实换行。

■ 引用回复
  微信的引用回复会长这样：
      "被引用的那句话"
      ------
      我真正的回复
  请完整保留，写成：\"引用原文\"\n------\n我的回复
  不要只留回复，也不要只留引用。

■ 系统提示
  「通话时长01:12:59」「你撤回了一条消息」「XX 拍了拍我」这类，保留，说话人写「系统」：
      系统：通话时长01:12:59

【最后自检，逐条回答 yes/no，全部 yes 才输出】
1. 文字消息条数，和我从原文数出来的一致吗？
2. 每条消息的说话人，和原文一致吗？
3. 所有 [晕] [大哭] 这类表情、所有 😱🥹 这类 emoji，都还在吗？
4. 所有媒体消息（[图片][视频][语音][文件][链接]…）都丢弃了吗？
5. 顺序和原文一致吗？我有没有偷偷排序？
6. 有没有任何一条被我改写过？
7. 每一行都只有一条消息，没有出现真实换行吗？

【如果记录很长】
不要一次输出。先告诉我总共大概多少条，然后每 200 条输出一批，
每批之间只写一行「--- 第 N 批，共 M 批 ---」，不要其他任何说明文字。
````
