# 第 6 步：清洗

**产出**：`work/data/clean.jsonl`、`work/reports/6-clean.md`

## 跑

```powershell
cd learn
..\.venv\Scripts\python.exe pipeline\clean.py
```

## 规则

「不作 target」= 留在数据里当上下文，但不算训练目标。「删除」= 真删。

| 规则 | 判据 | 处置 |
|---|---|---|
| R1 系统消息 | `role = system` | 不作 target |
| R2 引用结构不完整 | `quote_no_reply` / `no_quote` / `multiple` | 不作 target |
| R3 外部粘贴（AI 味） | 结构化打分 ≥ 4 且 > 200 字 | 不作 target |
| R4 长英文书信 | 拉丁字母占比 > 70% 且 > 200 字 | 不作 target |
| R5 超长单条 | > 300 字 | 不作 target |
| R6 隐私 | 手机号 / 身份证号 | 替换 `<phone>` `<id>` |
| R7 脱敏占位符 | 含 `[敏感数据已脱敏]` | 剔除占位符，保留其余文字 |
| R8 低信息 | 有效字符 < 2 | 不作 target |
| R9 重发 | 同会话、与上一条完全相同、≤ 60 秒 | **删除** |

R3 的结构化打分：`**加粗/标题` +3、编号列表 ≥2 行 +2、小标题冒号 +2、箭头链 ≥2 个 +1、无口语词 +1、无「你/我」+1。

## 为什么这样定（实测依据）

| 一开始想写的规则 | 实测 | 改成 |
|---|---|---|
| 英文 = 污染，删 | 218 条英文是**他本人写的**（`Actually, I feel quite comfortable speaking in English than typing`） | 短英文保留，只排除 > 200 字书信体 |
| 关键词判 AI：`首先` `其次` | 误报 —「首先我觉得这个公众号有点奇怪」是真人说话 | 不用关键词，用结构化打分 |
| 关键词判代码：`class` `import` | 5 条全是英文句子里误匹配 | 删掉这条规则 |
| 完全重复 = 噪声，删 | 1,007 对重复里 889 对跨会话（`好的好的`×10、`这样啊`×4 是口头禅） | 只删同会话 60 秒内的重发 |
| 纯表情/单字 = 退化，删 | `me` 里 171 条有效字符 <2（`？`×19）是真实语体 | 不删，只不作单独 target |
| 长文 = 污染，删 | 60 条 >400 字里绝大多数是真人深夜长信（有口语词、有表情、有你/我） | 只排除 > 300 字，防模型学成长篇大论 |

真正的污染只有三处：**4 条 AI 粘贴**、**75 条 `[敏感数据已脱敏]` 假词**、**1 处手机号**。

## 闸门

| 闸门 | 标准 |
|---|---|
| `me` 可训练比例 | ≥ 80% |
| 手机号 | 剩 0 条 |
| 脱敏占位符 | 剩 0 条 |

## 改配置

`config/persona.yaml` 的 `clean:` 段：

```yaml
clean:
  max_target_chars: 300       # 想保留长文风格就调大
  max_english_chars: 200      # 想学英文写信就调大
  ai_score_min: 4
  ai_min_chars: 200
  merge_resent_sec: 60
  mask_privacy: true
```

## 出问题怎么办

| 现象 | 处理 |
|---|---|
| `me` 可训练比例 < 80% | 看报告「其中 me」列，哪条规则吃得最多就调哪个阈值 |
| R3 误伤真人消息 | `ai_score_min` 调到 5，或把分档写进报告对照 |
| 想保留长文/英文 | 调大 `max_target_chars` / `max_english_chars`，重跑 |
| 报告里 R9 命中很多 | 你的记录被导出了两遍，检查第 1 步 |
