# 第 11 步：评测

**产出**：`work/reports/11-eval.md`、`work/eval/samples.md`、`work/eval/gen.json`

## 跑

```powershell
cd learn
..\.venv\Scripts\python.exe pipeline\eval.py
```

12 条样本、两个模型各生成一次，约 5 分钟。

只改指标不想重新生成（生成结果缓存在 `gen.json`）：

```powershell
..\.venv\Scripts\python.exe pipeline\eval.py --reuse
```

`--which base` / `--which tuned` 只跑一边，`--n 20` 加样本量。

## 它做什么

| 步 | 动作 |
|---|---|
| 1 | 从验证集挑 12 条，短/中/长各三分之一 |
| 2 | 原模型、微调后各回一次（同一段上下文） |
| 3 | 跟他的真实回复比四项：字数、句数、口头禅密度、格式污染 |
| 4 | 写报告 + 逐条对照 |

## 指标怎么读

| 指标 | 本机实测 | 说明 |
|---|---|---|
| 平均字数 | 真实 22 / 原模型 135 / 微调 19 | 差 6 倍就是「不像微信聊天」 |
| 平均句数 | 真实 1.7 / 原模型 4.6 / 微调 1.6 | 他会连发短句，不是一段话 |
| 口头禅密度 | 真实 4.9 / 原模型 1.0 / 微调 1.8 | 每百字命中他自己的说法几次 |

口头禅库不是「常见词表」，是**他比对方用得多 2.5 倍以上**的 2~5 字短语（`我发现`、`但是我`、`竟然`、`😅😅`）。用高频词表会让原模型刷满分，因为它写得长，怎么都能撞上。

## 闸门

| 闸门 | 标准 |
|---|---|
| 生成非空 | 空回复 ≤ 20% |
| 长度像真人 | 在真实均值的 0.4 ~ 2.5 倍之间 |
| 没有 AI 腔 | 0 条（结构化打分 ≥ 4 且 > 200 字） |
| 没有串名字 | 生成的回复里不冒出对方名字 |
| 口头禅密度不低于原模型 | ≥ 原模型的 90% |

## 出问题怎么办

| 现象 | 处理 |
|---|---|
| 字数远超真实 | 学歪成助手腔了。回第 10 步看 eval 曲线，用更早的 checkpoint |
| 口头禅密度低于原模型 | 学得太浅，回第 8 步把 epochs 或 rank 调大再训 |
| 出现 markdown / 列表 | 训练样本混进了 AI 长文，回第 6 步查 `ai_score` |
| 空回复多 | 温度太低，或第 7 步样本里 target 太短 |
| 一直说 `[表情]` 不接话 | 生成偏向安全回复，加样本量再看 |


## 贴题率：硬指标

像不像可以让步，**有没有跑题、有没有说反话不能**。

做法：用基座模型当裁判，逐条问

> 这条回复有没有引入跟对话完全无关的新话题，或者说了和对方说的相反的情况？
> 简短、情绪化的反应也算贴题。

这个问法必须这么写。早期版本问的是「有没有在回应对方」，结果他本人的真实回复只拿到 31%——因为「好嘟」「好冷漠」这类应答本来就不重复对方的话，而助手式的长篇回应反而拿 100%。问错了就会把「像人」判成「不合格」。

本机实测（n=40）：

| 来源 | 贴题率 |
|---|---|
| 真实（他本人） | 85% |
| 原模型 | 100% |
| 微调后 | 87% |

闸门设两个下限，缺一不可：

| 下限 | 理由 |
|---|---|
| ≥ 真人 − 5pp | 不能比本人还跑题 |
| ≥ 原模型 − 20pp | 微调不能把「听话」练废 |

还有 `自我重复`：同一段回复里 2-gram 重复率超过 1/3 就是在绕圈子。

## 扫 checkpoint 挑最好的

不要靠反复调学习率试错。训练时每 10% 存一档，直接扫：

```powershell
..\.venv\Scripts\python.exe pipeline\eval.py --sweep --apply
```

每档生成同样几组回复，算综合分：

```
综合分 = 接话度 45% + 长度 20% + 口头禅 20% + 句数 15%
```

分数最高的那档复制成 `work/adapter_best/`，后面导出就用它。

## 别只看指标

指标只负责筛异常。像不像一个人，得读 `samples.md` 里那 12 组对照。
