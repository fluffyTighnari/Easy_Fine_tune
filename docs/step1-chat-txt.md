# 第 1 步：拿到 chat.txt

**产出**：`work/input/chat.txt`（目录不存在就自己建一个，`work/` 就放在 `learn/` 下）

## 格式

一行一条：

```
[2026-04-01 11:21:32] 人物B：你好
人物A：没有时间戳的消息不写方括号
```

- `说话人：内容`，中文全角冒号
- 时间戳可选，格式 `[YYYY-MM-DD HH:MM:SS]`
- 消息内的换行写成 `\n`
- 内容不许改：错别字、表情、语病全部保留

## 介质规则

| 消息类型 | 处理 |
|---|---|
| 文字 | 保留原文 |
| 系统（通话时长、撤回、拍一拍） | 保留，说话人写 `系统` |
| 图片、视频、语音、文件、链接、位置、表情包 | **整条删除** |
| `[晕]` `[大哭]` 这类微信表情 | 保留 |
| 😱 🥹 ‼️ 这类 emoji | 保留 |

## 做法 A：让 AI 转（推荐）

1. 打开任意 AI
2. 把 `prompts/wechat_copy_to_chat_txt.md` 里的代码块整段粘进去，发送
3. 在同一对话里贴聊天记录，每次 200~500 条；先说明「分几次发，收完再输出」
4. 把输出存成 `work/input/chat.txt`，UTF-8 编码

## 做法 B：手工整理

1. 把原件贴进编辑器
2. 微信复制的三行结构（昵称 / 时间 / 内容）拼成一行
3. 删掉整行是媒体占位符的（`[图片]` `[视频]` `[语音]` `[文件]` `[链接]`）
4. 消息内的换行替换成 `\n`
5. 跑下面的自检，按报错改

## 做法 C：自己写脚本

有结构化导出（json/csv）且量大时：

1. 读来源，摊平成 `[{sender, content, sent_at, type}]`
2. 按上面的介质规则过滤
3. 用 `lib/chat_txt.py` 写文件并校验：

```python
from lib import chat_txt
chat_txt.render(records, "work/input/chat.txt")
print(chat_txt.verify(records, "work/input/chat.txt"))   # 必须 ok
```

参考实现：`test/tools/wechat_to_standard.py`（本项目一次性用的，不要当框架用）

## 自检

```powershell
cd learn
..\.venv\Scripts\python.exe lib\chat_txt.py --check test\input\chat.txt
```

看四个数：

- `失败：0`
- 说话人个数（几个自然人）
- 目标人物占比 ≥ 10%
- `命中媒体闭集：0`

失败率 ≤ 5% 可继续，> 5% 先修数据。

## 报错对照

| 报错 | 原因 | 修法 |
|---|---|---|
| `no_colon` | 该行没有 `名字：`，多半是消息内含换行被拆成两行 | 接回上一行，中间写 `\n` |
| `no_colon` | 微信三行结构只拼了一半 | 拼成 `[时间] 名字：内容` |
| `empty_sender` | 冒号前是空的 | 补说话人 |
| `sender_too_long` | 内容里的冒号被当成说话人分隔 | 补真正的 `名字：` |
| `suspicious_sender` | 时间没放进方括号 | 改成 `[2026-04-01 11:21:00] 名字：` |
| 解析通过但有 `[图片]` | 媒体消息没删 | 整行删除 |
| 解析通过但 `[晕]` 变成「晕」 | AI 润色了 | 换模型重转 |
