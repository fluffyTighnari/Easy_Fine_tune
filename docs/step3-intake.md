# 第 3 步：读入与体检

**产出**：`work/data/messages_raw.jsonl`、`work/reports/3-intake.md`

## 跑

```powershell
cd learn
..\.venv\Scripts\python.exe pipeline\intake.py
```

换输入：加 `--input 路径`。

## 报告看什么

| 项 | 要判断的 |
|---|---|
| 条数 | 和你预期差太多就回第 1 步 |
| 说话人 | 几个自然人；目标人物占比 ≥ 10% |
| 时间跨度 | 覆盖多久 |
| 顺序 | 倒序 / 升序 / 混乱（第 4 步会修） |
| 估算会话数 | 间隔 > 30 分钟断开 |
| 长度 p50 / p90 | 后面定截断长度用 |
| 引用块 / 重复 / 长文 | 第 4、6 步要处理的量 |

## 闸门

不通过就停，回第 1 步。

| 闸门 | 标准 |
|---|---|
| 解析失败率 | ≤ 5% |
| 说话人数 | ≥ 2 |
| 媒体占位符 | 剩 0 条 |

## 出问题怎么办

| 现象 | 处理 |
|---|---|
| 说话人只有 1 个 | 只导出了单方消息，重新导出 |
| 某个人占比 < 10% | 你导出的多是对方的话，学不出目标人物 |
| 媒体占位符没清空 | 回第 1 步删掉 `[图片]` 那些整行 |
| 时间格式无法解析 | 回第 1 步统一成 `[YYYY-MM-DD HH:MM:SS]` |
| 解析失败 > 5% | 回第 1 步，按报错对照表修 |
